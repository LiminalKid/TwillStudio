# Factory kit

The drum samples Twill Studio installs as its factory kit, recorded for it from an analog drum
machine. They're built into the app (`cmake/embed.cmake`) and written to `samples/Factory/` on first
launch.

These samples are dedicated to the public domain under CC0 1.0 (see `LICENSE` here): use them for
anything, in any music, with or without credit. The rest of Twill Studio is under the GPL-3.0
(`../../LICENSE`).
