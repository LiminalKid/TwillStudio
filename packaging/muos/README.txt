TWILL STUDIO FOR MUOS

A piano-roll groovebox. It needs nothing else installed (not PortMaster).

INSTALL
1. Copy TwillStudio-muOS.muxapp, as it is, into ARCHIVE on the SD card.
2. On the handheld, open Archive Manager from Applications and choose it.
3. Start Twill Studio from Applications.

QUIT
Select + Start, Menu + Start, or Quit Twill at the end of the main menu. The song is saved.

UPDATE
Install the new version the same way. Your songs stay.

YOUR FILES, in TwillStudio at the top of the first SD card
projects/   saved songs (the one you're working on is also saved as autosave.twill)
samples/    your own samples
renders/    songs rendered to WAV, and stems
log.txt     what happened on the last run, for bug reports
(If Twill Studio was already installed through PortMaster and has songs, they stay in ports/twill
and both versions use them.)
